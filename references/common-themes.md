# 游戏行业常见反馈主题参考

分析玩家反馈时可优先对照以下高频主题，提高聚类效率与一致性。

## 核心体验类
- 操作手感 / 打击感 / 响应延迟
- 难度曲线（过难、过简单、卡关点）
- 核心循环疲劳 / 重复感
- 引导与新手体验
- 存档 / 进度丢失问题

## 数值与成长
- 养成速度过慢或过快
- 数值膨胀 / 战力压制
- 资源产出与消耗不平衡
- 付费与免费差距过大（Pay to Win 感知）

## 内容与更新
- 内容量不足 / 更新频率
- 活动单一或重复
- 剧情质量与节奏
- 地图 / 关卡设计问题

## 社交与匹配
- 匹配时间长 / 匹配不公平
- 组队体验差
- 社交功能缺失或鸡肋
- 负面社交行为（挂机、辱骂等）

## 技术与性能
- 闪退、卡顿、发热、耗电
- 加载时间过长
- 不同设备表现差异
- 网络延迟与同步问题

## 商业化与运营
- 商城价格与性价比
- 广告频率与打断感
- 限时压力与焦虑设计
- 客服响应与售后体验

## 表现与视听
- 画质、特效与角色表现冲突
- 音效 / 配乐质量
- UI/UX 易用性
- 镜头与视觉信息过载

使用建议：先把原始反馈归入上述大类，再在大类下细分具体问题。避免一上来就创造过多新主题。
