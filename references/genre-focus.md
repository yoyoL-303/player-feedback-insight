# 不同品类玩家反馈侧重点差异

分析反馈时，先判断游戏大致品类，再调整对「什么更重要」的权重。同一句话在不同品类里的优先级可能完全不同。

## 动作 / 动作角色扮演（ARPG、类魂、横版动作等）
高权重关注点：
- 操作手感、打击感、前摇后摇、连招流畅度
- 特效与角色/武器的视觉平衡
- 镜头距离、角色体量、受击反馈
- 难度曲线与「死亡是否公平」
- 武器/技能的手感差异是否明显

低权重或需谨慎对待：
- 单纯剧情吐槽（除非严重影响动机）
- 养成速度（除非严重影响战斗验证频率）

## 二次元养成 / 卡牌 / 收集养成
高权重关注点：
- 抽卡概率、保底、天井体验
- 养成资源获取速度与日常压力
- 角色强度与环境变更频率（是否频繁逼氪）
- 剧情质量与角色塑造
- 体力 / 体力药设计是否造成焦虑

低权重或需谨慎对待：
- 纯操作手感（除非是动作二次元）
- 单局战斗的微操作细节

## 开放世界 / 沙盒
高权重关注点：
- 探索动力与「空虚感」
- 内容密度 vs 地图大小
- 任务引导是否过多或过少
- 载具、攀爬、战斗等基础操作的舒适度
- 后期内容是否支撑得住探索欲

## SLG / 策略 / 模拟经营
高权重关注点：
- 数值平衡与「算得清」的程度
- 多人对战/匹配公平性
- 养成线是否过长或过肝
- 策略深度 vs 微操作负担
- 联盟/社交系统的健康度

## 超休闲 / 轻度
高权重关注点：
- 前几秒是否有趣、是否容易理解
- 广告频率与打断感
- 单局时长是否合适
- 失败是否令人想再来一次
- 付费点是否生硬

## 通用原则
- 先识别品类，再决定哪些主题应该被抬高优先级
- 玩家用其他游戏做对比时，优先看他对比的是「同品类标杆」还是跨品类
- 品类核心体验被损害时，即使反馈条数不多，也应提高优先级
