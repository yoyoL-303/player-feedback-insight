# player-feedback-insight

把杂乱的玩家反馈快速转化为可执行的洞察报告。

专为游戏策划 / 产品经理设计，帮助你从社区评论、问卷、客服记录中提取真实痛点，并给出优先级建议。

## 功能特点

- **主题聚类**：自动把反馈归类成清晰主题
- **真伪判断**：区分高频真实痛点、伪需求和个人噪音
- **品类感知**：根据游戏类型（动作、二次元养成、开放世界、SLG、超休闲等）调整分析权重
- **多种输出**：
  - 结构化文字版
  - 专业 Word / PDF 文档
  - PNG 页面预览图

## 使用方法

1. 将整个文件夹放入 Grok 的 skills 目录
2. 在对话中粘贴玩家反馈，并说明需要分析
3. 如需正式文档，可以说「生成文档」「出报告」或「要 PNG 版式」

## 适用场景

- 版本复盘前快速消化玩家意见
- 迭代规划时识别高优先级问题
- 内部同步「玩家到底在说什么」
- 减少被个别情绪化反馈带偏的风险

## 示例触发方式

- 「帮我分析这些玩家反馈」
- 「这些评论里哪些是真痛点」
- 「生成一份反馈洞察报告」
- 「出 Word 版 + PNG」
